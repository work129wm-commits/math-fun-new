# رياضيات ممتعة

موقع عربي RTL بتصميم وردي وأبيض. حافظت هذه النسخة على تخطيط وتصميم الواجهة السابق، وعدّلت الاسم إلى **رياضيات ممتعة**، وغيّرت التسمية إلى **أستاذ**، وأضفت تسجيل دخول فعليًا عبر Supabase Auth بالبريد الإلكتروني وكلمة المرور.

## إعداد تسجيل الدخول مع Supabase

في ملف `index.html` ابحثي عن الإعدادين قرب بداية JavaScript:

```js
const SUPABASE_URL='https://dkhjaooornsykoprnclcy.supabase.co';
const SUPABASE_PUBLISHABLE_KEY='PASTE_YOUR_SB_PUBLISHABLE_KEY_HERE';
```

ضعي عنوان مشروعك في `SUPABASE_URL` إذا كان مختلفًا، وضعي **Publishable key** أو مفتاح `anon` العام في `SUPABASE_PUBLISHABLE_KEY`. لا تضعي `service_role` أو أي مفتاح سري في ملف الموقع.

يلزم كذلك أن تكون المصادقة بالبريد وكلمة المرور مفعلة في Supabase Auth، وأن يوجد جدول `profiles` بهذه الأعمدة على الأقل:

- `id` مرتبط بمعرّف المستخدم نفسه في `auth.users`.
- `display_name` اسم العرض.
- `role` تكون قيمته `student` للطالبة أو `teacher` للأستاذ.

بعد نجاح المصادقة، يتحقق الموقع من دور الحساب في `profiles` ويقارن الدور بالاختيار على شاشة الدخول. يجب إعداد سياسات RLS مناسبة على الجدول؛ لا تعتمدي على إخفاء الواجهات لحماية البيانات.

## تشغيل ورفع المشروع

افتحي `index.html` مباشرة أو شغليه عبر Live Server. لرفعه إلى GitHub Pages، ارفعي الملفات المفكوكة إلى مستودع GitHub ثم اختاري من **Settings → Pages** النشر من فرع `main` ومجلد `/ (root)`.

## ملاحظة عن بقية الوظائف

تم ربط **تسجيل الدخول وتسجيل الخروج** بـ Supabase. المكتبات والرسائل والتنبيهات والواجبات والدرجات في هذه النسخة ما زالت نموذجًا تجريبيًا محفوظًا محليًا في المتصفح، وليست مزامنة متعددة المستخدمين. يلزم ربط تلك الأجزاء بجداول وسياسات RLS وRealtime وStorage في Supabase قبل استخدامها فعليًا مع الطالبات.
