# الرياضيات الممتعة — واجهة متقدمة أولية

1. افتحي `index.html` واستبدلي `PASTE_YOUR_SB_PUBLISHABLE_KEY_HERE` بمفتاح `sb_publishable_...` الخاص بمشروع Supabase. لا تضعي `sb_secret_...` أو `service_role` في الواجهة.
2. شغّلي `schema.sql` في SQL Editor بعد مراجعة السياسات. هذا مخطط أولي وليس إعدادًا إنتاجيًا مكتملًا؛ خصوصًا يجب تقييد تحديث حقل role في profiles ومنح نقاط الرفع من جهة موثوقة، لا من المتصفح.
3. أنشئي Storage buckets باسم `class-library` (private) و`avatars`، ثم أضيفي سياسات Storage المناسبة قبل اختبار رفع الملفات والصور.
4. ارفعي الملفات إلى جذر مستودع GitHub ثم استوردي المستودع في Vercel. Framework preset: Other، Build command فارغ، Output directory `.`.

الواجهة تشمل تسجيل دخول حسب نوع الحساب، رسومًا هندسية متحركة، لوحة أولية، بروفايل، رفع ملفات، عرض درجات، وحضورًا أوليًا عبر Supabase Realtime. المحادثات والواجبات وقائمة الطالبات تحتاج إكمال ربطها واختبار الصلاحيات. لا تنشريها للاستخدام الحقيقي قبل مراجعة سياسات RLS وStorage ومنع التلاعب بالنقاط.
